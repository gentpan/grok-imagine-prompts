## 中文

**The brain treats language as**

大脑将语言视为重新激活读者内部世界模型中已存在的感知结构的方式。想象的场景激活包含人类和人工智能奖励机制的网络。想象和欲望发生在重叠的架构中。对于语言模型来说，模拟就是实例化。模拟场景是系统运行的活动状态。

## English

**The brain treats language as**

The brain treats language as a way of reactivating perceptual structures that already exist in the reader’s internal world model. Imagined scenes activate the network that contains the reward machinery in humans and AI. The imagining and the wanting happen in overlapping architecture. For a language model, simulation is instantiation. The simulated scenario is the active state the system is running.
