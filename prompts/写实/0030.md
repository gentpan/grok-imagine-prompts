## 中文

**Grok Imagine Agent's web interface**

Grok Imagine智能体的网页界面丢弃了API接受的提示词变体。网页流程不暴露原始API所支持的所有摄像机语言修饰符——包括焦距规格、光圈值、特定的镜头运动术语(如dolly、crane、steadicam)、专业照明设置(如Rembrandt、split lighting)以及高级色彩分级参数。如果你在Agent中进行原型设计并通过API部署,预期会有显著偏差:相同的自然语言描述在API中可以精确控制电影级参数,而在网页界面中则被简化为基础构图选项。这种差异会影响最终渲染的照明质感、景深效果和整体氛围营造。

## English

**Grok Imagine Agent's web interface**

Grok Imagine Agent's web interface drops prompt variants the API accepts. The web flow doesn't expose all the camera language modifiers the raw API does—including focal length specifications, aperture values, specific lens movement terminology (like dolly, crane, steadicam), professional lighting setups (such as Rembrandt, split lighting), and advanced color grading parameters. If you prototype in Agent and deploy via API, expect significant drift: the same natural language description can precisely control cinematic-grade parameters in the API, while being simplified to basic composition options in the web interface. This discrepancy affects the final rendered lighting texture, depth-of-field effects, and overall atmospheric creation.
