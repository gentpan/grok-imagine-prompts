## 中文

**This is because imagination uses**

这是因为想象使用与感知相同的神经机制。当你想象看到某物时，激活的视觉皮层区域与你实际看到它时相同。当你想象移动时，你的运动皮层的参与方式与你实际移动时相同。

## English

**This is because imagination uses**

This is because imagination uses the same neural machinery as perception. When you imagine seeing something, the same visual cortex regions activate as when you actually see it. When you imagine moving, your motor cortex engages the same way it would if you were actually moving.
