## 中文

**Reve creates the image 'like**

Reve"像编写代码一样"创建图像,通过直接重写结构化的视觉布局而非自然语言提示词来进行精确编辑。这种方法允许对图像元素的位置、大小、光照和材质进行程序化控制,类似于在代码编辑器中修改参数。每个视觉组件都可以被独立调整——改变对象的xyz坐标、调整光源的强度和色温、修改材质的反射率和粗糙度——而无需重新生成整个场景。Ideogram采用相似的技术路径,通过JSON格式的结构化描述符来定义场景,实现了对构图、相机参数和光照设置的细粒度控制。这种"声明式"的图像创建范式,将创意工作流从模糊的文本描述转变为精确的参数化编程。

## English

**Reve creates the image 'like**

Reve creates the image 'like code', editing by directly rewriting structured visual layouts rather than natural language prompts for precise editing. This approach allows programmatic control over image elements' position, size, lighting, and materials, similar to modifying parameters in a code editor. Each visual component can be independently adjusted—changing an object's xyz coordinates, adjusting light source intensity and color temperature, modifying material reflectivity and roughness—without regenerating the entire scene. Ideogram employs a similar technical path, defining scenes through JSON-format structured descriptors, achieving fine-grained control over composition, camera parameters, and lighting setups. This "declarative" image creation paradigm transforms the creative workflow from ambiguous text descriptions into precise parametric programming.
