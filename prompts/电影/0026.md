## 中文

**The actual rule for production**

生产路由的实际规则:选择你可以吸收其失败模式的模型,而不是总分最高的模型。摄像机heavy的叙事镜头使用Grok Imagine 1.5 API并配对单独生成的音频。具有单轴摄像机的氛围heavy镜头,Seedance 2.0一次性为你提供母带处理的音频。

## English

**The actual rule for production**

The actual rule for production routing: pick the model whose failure mode you can absorb, not the one with the highest overall score. Camera-heavy narrative shots route Grok Imagine 1.5 API and pair with separately-generated audio. Atmosphere-heavy shots with single-axis camera, Seedance 2.0 gets you mastered audio in one pass.
