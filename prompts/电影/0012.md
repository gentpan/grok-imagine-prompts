## English

**Been running horror scenes through**

Been running horror scenes through Grok Imagine 1.5 preview API. Image quality is solid. The issue isn't quality, it's unprompted behaviors the model adds without being asked. What I keep catching: Unprompted fade-in and fade-out between cuts. Prompt doesn't mention transitions. Grok inserts them anyway between consecutive shots. Reads like the model defaults to "transition exists" instead of "no transition specified means hard cut." Breaks rhythm on horror scenes where you want abrupt cuts. Stiff dialogue performance even when no dialogue is in the prompt. Prompts that don't specify dialogue still get audio with approximate lip-sync and wooden delivery. Production fix: add explicit "no dialogue, ambient audio only" as negative. Works. Unnatural performance when character action is specified plainly. "Woman looks toward the door" gets you a stiff head turn with frozen body language. Compare with "woman slowly turns her head, body leans away in fear" — explicit movement language overrides the stiffness. Plain action verbs aren't enough. Random physics effects firing unprompted. Falling debris, hair particles, lens flares appear without being asked for. Seems like the model's cinematic prior firing. Negative prompt "no falling particles, no lens flare, no debris" cleans it up reliably. The pattern: Grok Imagine 1.5 has strong cinematic defaults that fire unless explicitly negated. Other models tested in the same setup (Seedance 2.0 in particular) require explicit positive instruction to add these elements. Opposite ends of the prior-versus-prompt spectrum. Production routing implication: For controlled-output workflows (matching existing footage, preserving director intent), models that require explicit positive instruction are easier to manage. For exploratory or stylized work where the model's prior helps, strong-default models actually accelerate output. Side note: Grok API reference image upload is currently capped at 1 image per generation. Multi-character scenes need staged sequential generation rather than single multi-reference prompts. Generated on Seedance 2.0 and Grok Imagine 1.5 preview API. 6-8 second clips, horror genre prompts, tested both with and without negative prompts.
