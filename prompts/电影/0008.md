## English

**Been running identical prompts across**

Been running identical prompts across Grok Imagine 1.5 API and Seedance 2.0 without specifying camera framing. The output divergence isn't quality, it's compositional default. Each model falls back to a different shot type when you don't anchor one. Test setup: 5 character action prompts (warrior types, no scene specifier, no camera language). Same prompt verbatim into each model. What each model defaults to: Grok Imagine 1.5 falls back to mid-shot action photography. Subject takes 40-60% of frame. Wide enough to show body language and stance, tight enough to read facial expression. Background is typically alley, ruin, or moody environment with rim lighting. Composition reads as cinematic action photography aesthetic. Seedance 2.0 falls back to close-up portrait with prop detail. Subject occupies 70-85% of frame. Hands, weapons, jewelry, and texture work all rendered in detail. Background is decorative ornament or pattern, not environment. Composition reads as character study or fashion editorial. The production routing implication: if you don't write camera framing into the prompt, you're getting the model's preferred composition. Grok wants to show you action. Seedance wants to show you detail. Three downstream effects worth knowing: For sequential cuts in a narrative arc, this divergence breaks continuity hard. A Grok shot followed by a Seedance shot reads as a mid-shot suddenly cutting to extreme close-up. Even with identical character design, the viewer's eye reads the shot-size jump as a director choice (which it isn't). If you want close-ups, prompt Seedance and skip the framing. If you want action mids, prompt Grok and skip the framing. The shortcut works. But the shortcut also encodes whichever bias the model has, so reuse the same model for the whole sequence. For mixed-framing sequences you have to anchor every shot. "Wide shot, character entering frame from screen-left" / "extreme close-up on hands gripping weapon". Without explicit framing, both models drift back to their respective defaults. Generated through Seedance 2.0 on the same provider Grok runs through. 8-second clips, 1080p, no negatives applied for the test.
